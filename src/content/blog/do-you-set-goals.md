Goals. Some people set them, some people don’t.

Some people set a number of goals yearly.

Others don’t even consider setting goals.

Still others think about it, maybe even worry that they should be setting them, but never seem to actually set any goals.

**Let me** **say, it’s okay – regardless of which “goal-setting camp” that you are in, your mother still loves you!**

Some people in my family would rather never set any goals.

I, on the other hand, really embrace goal setting.

Goal setting is a choice that’s up to you.  “Thou shalt set goals” is not written somewhere in stone!
